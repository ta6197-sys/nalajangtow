# 출처와 한계

- 원본: 사용자가 이 대화에서 첨부한 Docktimize 디자인 화면 이미지 3개.
- `01_상황확인.png`은 2048×607 복합 이미지의 **왼쪽 1개 화면만 크롭**했습니다.
- `02_후보비교.png`은 별도 첨부된 후보 비교 화면을 사용했습니다.
- `03_확정_보고서.png`은 별도 첨부된 확정·보고서 화면을 사용했습니다.
- 문서의 수치와 표현은 화면에 나타난 **시연용 정보**입니다.
- 정적 이미지로는 화면에 표시되지 않은 스크린, Figma 레이어 구조, 컴포넌트 속성, 프로토타입 연결, 데이터 구조 및 작동하는 소프트웨어를 추출할 수 없습니다.
- 후보 비교에서 사용된 `제약 위반 0건`은 디자인에 적혀 있는 값이며 실제 CP-SAT 검증을 수행하지 않았습니다.
- `15:00` 마감표시는 UI 예시일 뿐, 울산항 또는 SK CLX의 공식 운항 일정 확정 마감시각을 의미하지 않습니다.
- 작은 크기의 복합 캡처 안에만 있는 1번 화면의 일부 숫자·세부 문구는 정확하게 읽기 어려워서 상세 명세에 단정적으로 기록하지 않았습니다.
