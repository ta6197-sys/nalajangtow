# Docktimize — 선박 스케줄러 부분 추출본

이 ZIP은 사용자가 제공한 Docktimize Figma **화면 캡처 3장**에서 **선박 스케줄러** 부분만 분리한 자료입니다.

## 구성

- `index.html`: 오프라인에서 화면 3개와 요약을 확인하는 페이지 (브라우저로 열기)
- `screens/01_상황확인.png`: 상황 확인 화면 (복합 캡처에서 해당 영역만 추출)
- `screens/02_후보비교.png`: 최적화 후보 비교 화면
- `screens/03_확정_보고서.png`: 접안 순서 확정 및 보고서 화면
- `spec/화면별_기능명세.md`: 화면별 핵심 정보·동작·화면 간 연결
- `spec/UI_요소목록.csv`: 화면에 표시된 주요 구성 요소
- `spec/샘플_화면값.json`: 캡처에서 판독 가능한 디자인 예시 값
- `spec/사용자흐름.mmd`: Mermaid 형식 사용자 흐름
- `spec/출처와_한계.md`: 추출 근거 및 확인되지 않은 항목

## 핵심 흐름

**상황 확인 → 최적화 후보 비교 → 위험 검토 → 일정 확정 → 보고서 확인·공유**

## 구분해서 이해할 사항

1. 본 자료는 **원본 Figma 편집 파일(.fig)이나 Figma 프레임/컴포넌트 원본이 아닙니다.** 이미지 기반 추출본입니다.
2. `screens/` 이미지는 캡처에서 잘라내거나 그대로 가져왔으며, 편집 가능한 디자인 레이어가 아닙니다.
3. 체선료·선박·시각·위험 등의 수치는 **화면 속 예시 값**입니다. 실제 운항정보나 최적화 결과로 검증된 값이 아닙니다.
4. 보이는 UI 구성요소는 확인할 수 있지만 실제 버튼 동작, 권한, 알림, 서버 연동 등은 **정적 이미지에서 확인되지 않습니다.**
5. 1번 화면은 원본에서 작은 크기로 포함된 영역이므로 세부 글자 일부의 판독 정확도가 낮을 수 있습니다.
6. SK CLX의 실제 확정 마감시각이나 접안 제약으로 화면 속 `15:00`을 해석해서는 안 됩니다.

이 자료는 선박 스케줄러 부분을 개발팀에 전달하거나 기능 요구사항을 정리할 때 활용할 수 있습니다.
