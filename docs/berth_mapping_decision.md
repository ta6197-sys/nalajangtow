# 8선석 매핑 결정 기록 (사용자 승인 전 미확정)

현재 기존 `config/berth_mapping.json`의 모든 `BERTH-01..08` 값은 `null`입니다.

`data/sk_facilities.json`의 SK 시설 코드 후보는 다음과 같습니다.

- 원유 부이: `SKB#2`, `SKB#3`
- 부두: `SK#1-1`, `SK#1-2`, `SK#2-1`, `SK#2-2`, `SK#2-4`, `SK#2-5`, `SK#2-6`, `SK#2-7`, `SK#3`, `SK#4-1`, `SK#4-2`, `SK#4-3`, `SK#5-1`, `SK#5-2`, `SK#5-3`, `SK#5-4`, `SK#5-5`, `SK#6`, `SK#7`, `SK#8`

**중요:** 위 목록은 물리 시설 후보 전체일 뿐, 현재 가상 선석 8개가 대응해야 할 대상을 의미하지 않습니다.

매핑 결정 이후에만 기존 `config/berth_mapping.json`을 수정하세요. 물리시설을 하나의 가상 선석으로 합치는 그룹 모델이라면 `BERTH-01 -> SK#1-1` 방식으로 매핑해서는 안 되며 모델의 수용능력·간섭 관계를 재설계해야 합니다.
