# V3 Phase 4: costed synthetic 72-hour search

The explicitly approved simulation uses `CLEAR_WEATHER_BASELINE_V1` (no additional weather interruption, not an observation) and `SECOND_PRECISION_SIMULATION_V1` (simulation contract policy, not legal settlement). Existing minute-boundary `contracts.py` remains unchanged. NOR, source notices, holidays, weather/exception credits and post-demurrage behavior remain those of the existing evaluator; no historical SOF is copied into new candidate events. Physical timestamps use integer seconds. Source laytime that is a rational fraction of a second is retained exactly in the accounting ledger; the policy's existing next-60-second exhaustion boundary, anchored to effective commencement, and final half-up USD-cent rounding are preserved. The original minute-aligned evaluator is checked by tests. Seven verified JSON rounding differences use the workbook formula as approved; source and JSON values are both returned. The optional exact-seconds extension does not change default Risk Engine behavior. Gross demurrage is optimized; no despatch or net settlement assumption is asserted.

`optimize_72h(snapshot, *, as_of_at, policy, settlement_records, ..., pricing_policy, time_limit_seconds, ...)` generates or accepts a finite set of ETBs, proposes complete physical schedules, independently checks berth constraints, assigns one connected tank per vessel, exactly projects 30 tank inventories and evaluates each candidate's gross demurrage. It retains the least-cost validated incumbent through subsequent infeasibility and timeouts; the outer time budget includes model construction and the final independent validation may add overhead. Only exact complete assignments are excluded; unresolved subproblems do not become infeasibility proofs. `SAFE_ENVELOPE_V1` is a conservative pair-conflict filter, independently checked against the original pair validator. `LOCKED_ONLY_V1` is an explicit narrower phase-release domain for diagnostic use, not a full-domain infeasibility proof.

Before returning an incumbent, a separate validator replays source/policy fingerprints, 72-hour call coverage, explicit commitments, berth rules, physical-work/tank-transfer intervals, exact inventory projection and settlement totals. The result is a synthetic simulation candidate and cannot confirm an operational schedule. The caller must supply real commitments and later observations; a synthetic prior projection does not establish actual Freeze authority. Candidate event knowledge and actual weather remain separate from the baseline. The model does not prove continuous-time optimality.
