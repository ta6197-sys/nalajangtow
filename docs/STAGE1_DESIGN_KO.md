## 1단계 — 정확한 종료 판정·데이터 범위 검사·시뮬레이션 출력 계약 (현재 전달)

**목적:** 기존 솔버/선석배정/탱크/계약 규칙을 건드리지 않고, 실행 상태와 시뮬레이션용 기초 출력의 신뢰성 확보.

**핵심:** `S20=(20척,3창)`, S20 필수 종료일은 2026-11-08 00:00 KST(11/03 시작 가정). `REQUESTED_WINDOWS_VALIDATED`와 `ALL_CALLS_COMPLETE`는 구별해야 함. 미래 공정유량이 끝난 경우는 정해진 기간을 모두 검증한 정상종료와 구분해야 함.

**구현물:** `v5_stage1_contract.py` / 단위테스트 / Codex 영어 지시서. `execution_outcome_v1`은 기존 `status`를 대체하지 않는 부가 필드. `build_window_descriptor`는 체크포인트에서 일정·물리 단계·탱크·정산·승계 상태를 손실 없이 추출하지만, 완전한 원본 데이터와 독립 Replay가 없으므로 위험도 계산의 기초 자료로 즉시 사용해서는 안 됨.

**통과 기준:** 기존 회귀 테스트 PASS, Stage-1 테스트 PASS, 저장 체크포인트 검증, 정상 종료와 미완료 선박 구분, 데이터 부족 분류, 원본/지문 불변. 실제 solver와 end-to-end 검증은 Codex의 실행 환경에서 진행.

## 2단계 — Rolling 이월·FIX/자동잠금·상태 승계·V5 zero-shock replay

- 일반 선박은 허용된 미배정 상태로 이월, 다음 창에 다시 후보 생성.
- FIX ETB와 시작·보호된 작업은 그대로 고정. 과거 ETA의 기존 배정이 없는 일반 선박에 자동잠금이 걸려 실패하지 않도록 잠금 조건과 상태 전이를 분리.
- 모든 선박을 반드시 현재 창에 배정하도록 만든 현재 선택 집합을 개선하되, 출처가 불명확한 결함이나 전역 물리 불가능을 무조건 이월로 변환하지 않음.
- 이월 횟수, 대기 시작, 경고 사유, 재검색, 미배정 집합, 계약 미확정 상태를 정확히 저장하고 독립 Replay 수행.
- V5 전용 Simulation Bridge: 검증된 이전 상태 + 원본·정책 + 물리 세그먼트 + 탱크·계약으로 충격 0 결과를 다시 실행하여 원래 V5와 동일한지 검증.

**통과 기준:** S5/S10/S20/R7/R14 회귀, 24h 상태·화물량·재고·계약 일치, FIX 보호, No-shock 일정/비용/재고 완전 일치. 이 결과가 없다면 3단계 금지.

## 3단계 — V5 리스크 재생 및 제한적 복구

- 세 가지 충격: ETA 도착 지연, 하역시간 증가, 기상 악화.
- `NO_RECOVERY`: 선석과 순서를 고정한 채 현실화된 지연 전파. 진행된 화물과 이미 종료된 작업은 수정 불가. 이송 물량 1bbl도 생성/소멸하지 않게 동일 총량, 실제 변화된 시간별 입출고와 원래 고정 공정유량으로 탱크 재계산.
- 충격 후 예상 체선료는 원래 V5 정산 모듈 재사용. 오류/미확정 발생 시 비용을 null로 두고 원인을 분리. 정상/물리불가능/정산미해결/시간부족을 나눔.
- `LIMITED_RECOVERY` 구현은 2단계 조건과 원래 FIX/동적잠금 보호를 정확히 지킨 경우에만 독립적으로 추가.

**통과 기준:** 충격 0 parity 유지, 3가지 충격 각각 재고·물리·정산 검증, 실패 상태 투명성, 반복 가능 scenario seed/fingerprint.

## 4단계 — A/B/C, 리스크 통계, 저장·웹·LLM

- A 체선료 최소, B 대기시간 최소, C 평시 안정성/충격 시 강건성. 실제 V5 경로에서 각각 검증된 후보 생성. 단순 라벨 변경 금지.
- 동일 선박 범위·동일 충격 시나리오에서 비용/대기/일정 변동성 비교. 실패 시나리오 비용을 0으로 채우지 않음. 불완전 분포에는 전체 VaR/CVaR 주장 금지.
- DB에는 source/policy/fingerprint, run/window, 후보, 이벤트, 재고, 비용, 충격과 리스크 결과를 불변 식별자로 저장. 웹에는 단순화한 비교·간트·재고·원인 그래프.
- LLM에는 검증된 구조화 결과만 제공, 일정·재고·체선료를 직접 조작하도록 하지 않음.
